# 水景 · 简体中文造景工具

**[Live Demo · 在线体验](https://skentsun.github.io/aquarium-editor/)**

通过 GitHub Pages 自动部署，推送到 `main` 分支后自动更新。

在本目录运行 `python3 -m http.server 8081 --bind 127.0.0.1`，访问 http://127.0.0.1:8081 。首次加载需要联网获取 Three.js。

界面已统一为深色主题，默认仅显示底部工具栏。造景、生物、环境、视角、作品面板按需打开，同一时间仅展开一个。素材面板加宽并随内容收缩，底床单排展示，石材和沉木采用素材与参数并排布局。底床、石材、沉木、水草、生物及环境均可编辑。支持中文搜索生物、撤销重做、示例、新建、保存与导入、导出图片、沉浸欣赏。移动端使用同一底部工具栏，宽面板按屏幕宽度自动换行。

性能监控：作品 → 性能监控。支持折叠或关闭，启动时默认隐藏；`?fresh` 用示例启动且不读写自动保存；`?layout=mobile` 可验证移动布局。

主要文件：
- index.html / studio.css / dock.css / dark.css：界面结构、底部工具栏、宽面板及深色主题
- ui.js / mobile.js：交互与素材面板
- catalog.js / invert.js：素材与生物目录
- layout.js：布局状态、场景概览和混养参考
- performance.js：整帧计数、异步 GPU 计时、实例化检查
- plant-batches.js：中后景和附生水草多绘制批处理
- main.js：场景启动与帧循环
- fish.js / plants.js / rocks.js / wood.js / tank.js：模型构建及渲染

所有金额、商业目录字段及打印报价逻辑已移除。模型 ID、资源路径与存档结构保留兼容；少数日文目录只给出属级名称，对应中文名称维持同等精度。


默认均衡画质已针对性能调整，关闭多重反射和景深、限制画布像素预算、降低阴影更新频率。流畅模式适合较低配置设备，精细模式保留昂贵效果。详见 PERFORMANCE.md。


交互约定：点击工具栏展开或收起面板；点击空白处或按 Esc 收起；选中物体时显示编辑条；选择放置或绘制工具后面板自动收起，底部显示状态与完成按钮；欣赏模式仅保留退出入口。

性能设置独立于环境面板，包含景深、画质档位和实时监控入口。造景示例采用横向实景预览卡片，共六套布局；新增青龙石原野、赤叶暮色、白砂溪岸、树根秘境，加载后可自由修改并撤销。

当前默认外观：精细画质、水面倒影开启、景深开启、白光、亮度 60%。底柜为纯深灰哑光。生物按分类标签页展示，无搜索框。鱼缸菜单已移除保存与导入、导出图片入口。

许可证：MIT，详见 [LICENSE](LICENSE)。

物体变换：选中后使用移动、旋转、缩放三轴控件，轴心位于物体几何中心。W/E/R 开始鼠标变换，X/Y/Z 限制轴向，Enter 或左键确认，Esc 或右键取消；Shift 精细调整，Ctrl 步进吸附。中键旋转视角，Shift＋中键平移。变换矩阵随布局保存并支持撤销。

变换控件只保留物体中心附近的有限轴向手柄，不显示无限延伸的拖动辅助线。

六套造景示例已按自然构图重做：石材成组并埋入地形，植物按高低和远近形成连续群落，底床增加局部坡度与弯曲留白。预览图来自相应布局的实际渲染。

GitHub Pages：本项目为纯静态页面，可从 main 分支根目录发布；`.nojekyll` 保证模型、贴图与模块按原路径直接提供。
